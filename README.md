功能

用安卓手机控制 Blender 相机旋转，在手机上实时取景，并把相机运动录成 XYZ 旋转关键帧。

准备

- Windows 电脑和 Blender（已在 Blender 5.1.2 测试，其他版本请先用空白工程试用）。
- Android 8.0 或以上、带陀螺仪的手机。
- 一根能传输数据的 USB 线。

1. 安装

电脑端：下载 [Blender 插件 ZIP](dist/phone_gyro_camera-1.2.1.zip)，在 Blender 的“编辑 → 偏好设置 → 插件”中选择“从磁盘安装”，安装后启用“手机陀螺仪相机”。ZIP 不用解压。

手机端：下载并安装 [安卓 APK](dist/GyroCamera-1.2.1.apk)。系统提示时，允许安装该应用。

2. 插线连接

1. 手机开启“开发者选项 → USB 调试”，用数据线连接电脑，解锁手机并确认“允许 USB 调试”。
2. Blender 的 3D 视图按 “N”，打开“手机相机”面板。
3. 选择目标相机，按实际握法选择“听筒在左”或“听筒在右”。保持“自动 USB”开启，点击 **开始监听**。
4. 手机应用会自动启动并连接。若没有进入前台，手动打开“手机陀螺仪相机”。不需要运行转发脚本或填写连接参数。

首次使用建议选择没有约束、驱动器和父级的相机。USB 无法识别时，换一根数据线，并检查 USB 调试授权；部分手机需要安装厂商驱动。

3. 取景和录制

1. 在 Blender 摆好相机初始朝向，并把时间线移到准备开始录制的帧。
2. 横握手机，点击 **以当前姿态归零**，再转动手机检查相机跟随。
3. 手机点击 **开始录制**：Blender 自动播放时间线，同时记录相机旋转。
4. 点击 **停止录制**：停止写入关键帧并暂停播放。
5. 在 Blender 点击 **停止监听**，回放检查动画，再保存工程。

觉得手抖明显，可以在 Blender 面板调大“旋转阻尼（秒）”；默认 0.12，数值越大越平稳，但跟随也越慢。

注意

- 录制会覆盖经过帧上已有的旋转关键帧。**请先备份工程，时间线循环播放也会覆盖同一段。
- 本工具只控制相机旋转，不控制位置和焦距。“录制”保存的是动画关键帧，不是视频。
- 手机画面是低分辨率视口预览，不是最终渲染。保留可见的 Blender 3D 视图；复杂场景卡顿时，先用实体着色或轻量场景测试。
- 手机保持解锁、应用保持前台。断连会停止录制，重连后需要重新点击开始。

不用数据线

电脑和手机连接同一可信局域网。Blender 开始监听后，在手机“连接设置”中选择 Wi-Fi，填写插件显示的电脑 IPv4 地址、端口和配对码，再点击连接。防火墙提示时允许 Blender 在私人网络通信。不要把监听端口开放到公网。
